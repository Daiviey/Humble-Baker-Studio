# The engine library

This project contains the parts of Humble Baker Studio that do not depend on a particular
window: the project model, synthesis, effects, mixing, mastering, rendering, export and the
`*.hbstudio.json` project format.

## `Engine/`

`Engine/` is imported from the PowerShell studio (which embedded the same C# and compiled it
with `Add-Type`). Each top-level type lives in its own file.

It is generated by `tools/extract-engine.ps1`. That script refuses to overwrite the folder by
default, because the port applies a small number of deliberate patches:

- `KnobPanel.cs`: wider knobs (108 px) and more space above category headers so parameter
  names are readable.

If you change the PowerShell source and want to re-import, run:

```powershell
powershell -ExecutionPolicy Bypass -File tools\extract-engine.ps1 -Force
```

Then re-apply the patches listed in `docs/PORT.md`.

## Additions on top of the import

| File | Purpose |
|---|---|
| `ProjectStore.cs` | Reads/writes the studio project format, including reflection-based patch/FX maps. |
| `ExportService.cs` | Offline render, WAV 16/24/32-bit writer, optional FFmpeg conversion. |
| `GlobalUsings.cs` | Shared imports for the extracted files. |

## Testing

`tests/HumbleBakerStudio.Audio.Tests` renders audio, checks determinism, round-trips projects,
and verifies WAV/MIDI file structure. Run `dotnet test` from the repository root.
